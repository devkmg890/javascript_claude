## 🔁 세션이 끊겼을 때 이어서 하는 법

1. VS Code나 Claude Code에서 이 폴더(`C:\git\javascript_claude`)를 엽니다.
2. Claude에게 이렇게 말하세요:

   > **"PROGRESS.md 보고 튜토리얼 이어서 진행하자"**

3. Claude는 `CLAUDE.md`(자동) → `PROGRESS.md` → 로드맵 순서로 읽고, 다음 단계부터 안내합니다.

> 💡 직접 하다가 중단할 때도 `PROGRESS.md`의 체크박스만 표시해 두면 됩니다.

## 🏗️ 최종 목표 구성 (미리보기)

```
 [브라우저]                 [우리가 만드는 서버 프로그램들]                 [DB]
 ┌──────────┐  HTTP   ┌──────────────┐   ┌────────────────┐
 │  React   │ ──────▶ │ API Gateway  │──▶│  auth-service  │──┐
 │  (화면)   │ ◀────── │  (입구/검문소) │   │ (로그인·토큰발급) │  │   ┌────────────┐
 └──────────┘         │              │   └────────────────┘  ├─▶ │ PostgreSQL │
                      │              │   ┌────────────────┐  │   └────────────┘
                      │              │──▶│  erp-service   │──┘
                      └──────────────┘   │ (재고·거래 등 업무) │
                                         └────────────────┘
```

운영 단계(Phase 11~)에서는 위 구성을 **클라우드 서버 3대**로 나눠 올립니다.

```
 인터넷 ─▶ [서버1: 웹/게이트웨이] ─내부망─▶ [서버2: auth·erp 서비스] ─내부망─▶ [서버3: PostgreSQL]
           (유일하게 외부 공개)              (외부 접근 차단)                  (외부 접근 차단, 백업은 외부 저장소로)
```
